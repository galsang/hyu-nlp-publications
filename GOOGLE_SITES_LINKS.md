# Links to Add on Google Sites (nlp.hanyang.ac.kr)

Base URL: **https://galsang.github.io/hyu-nlp-publications/**

## How to Add Links on Google Sites

1. Go to https://sites.google.com and open your site
2. Navigate to the **Publications** page (or the relevant category subpage)
3. Click the pencil icon to enter **Edit mode**
4. For each paper, add a text link or button: select the paper title → link icon (🔗) → paste the URL below (EN), and optionally add a second link to the KO page
5. Click **Publish** when done

KO page URL = EN URL with `ko/` inserted after the base, e.g. `.../ko/papers/{slug}.html`.
